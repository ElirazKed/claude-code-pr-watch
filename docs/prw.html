What it does

Every PR you care about, and everything you'd open GitHub for.

One screen for the PRs you wrote, the ones waiting on your review and the ones your agents opened, each worked out to the state that matters: conflicts, failing CI, changes asked for, ready to merge.

My PRs · searches · sessions

All your PRs in one place

Every open PR each of your gh logins wrote, a list for each GitHub search you save (review requests, a team's repos), and one per agent session: Claude through the mod, Codex and others through prw mcp or prw watch.

s · S

Sorted by what needs you

Most urgent first: conflicts, then failing CI, then reviews. Or by repo, oldest first, or quietest first. Each repo has a colour of its own, and every PR says when it opened and when it last moved.

Enter

The whole PR, full size

The conversation in the order it happened, review threads with the code they're on, checks with the end of each failed job's log, and the changed files. Markdown drawn as GitHub draws it.

r · x · a · c · m

Act without opening GitHub

Reply to a thread, resolve it or reopen it, approve, comment, and merge in the repo's method, or turn on auto-merge while checks run. It asks before a merge or an approval.

f

Hand it to your agent

Fix (failed checks, with their logs), Resolve (conflicts with the base) or Address (the open review threads): the prompt is copied for the agent that runs the PR.

a · gh meter

Every gh login, every budget

Each PR goes as the login that can see its repo, with that login's own token. A meter shows what's left of each login's GitHub budget, and with the mod running, one poll serves both, so no PR is asked for twice.

Keys, and the mouse

Built for the keyboard.

Every action is one key, shown on the bottom row. A click picks a list or a PR, a second one opens it, and the wheel scrolls the pane under it.

jk the next or previous PR
Enter open it full size
Tab the next list
s sort, S turn it around
m merge, after a y
c comment
r reply to a thread
x resolve it, or reopen it
a approve (full view)
f hand it off to your agent
o open it in the browser
? every key

Install

Running in a minute.

prw uses the GitHub CLI for everything, so log it in first (gh auth login). If gh is missing or logged out, prw tells you which.

The latest release

macOS and Linux (static), Intel and ARM, into ~/.local/bin, or $XDG_BIN_HOME where that's set.

$ curl -LsSf https://github.com/ElirazKed/claude-code-pr-watch/releases/latest/download/prw-installer.sh | sh

Every release also has its archives, with checksums and a GitHub attestation: gh attestation verify <file> --repo ElirazKed/claude-code-pr-watch.

Or with nix or cargo

Built from source, Rust 1.88 or newer for cargo.

$ nix run github:ElirazKed/claude-code-pr-watch#prw
$ cargo install --locked --git https://github.com/ElirazKed/claude-code-pr-watch prw

Using Claude Code?

The pr-watch mod keeps a live pane of the PRs a session touches, right beside the conversation. prw and the mod share one poll, and prw lists every Claude session's PRs on its own.
